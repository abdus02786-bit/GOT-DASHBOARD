# Game of Thrones Dashboard

An interactive Tableau dashboard that analyzes and visualizes **Game of Thrones episode data**. The dashboard provides insights into episodes, seasons, directors, ratings, and other key trends through interactive visualizations.

---

## 📌 Project Overview

This project focuses on exploring and analyzing the **Game of Thrones dataset** using Tableau.

The dashboard transforms raw episode-level data into meaningful visual insights, allowing users to explore different aspects of the popular television series.

The goal of this project is to demonstrate data visualization and dashboard development skills using **Tableau**.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze Game of Thrones episode data.
- Explore episode ratings and trends.
- Analyze episodes across different seasons.
- Identify directors and their contributions.
- Create interactive and visually appealing dashboards.
- Extract meaningful insights from the dataset.

---

## 📊 Dashboard Features

The Tableau dashboard includes interactive visualizations for analyzing:

- Game of Thrones seasons
- Episode information
- Episode ratings
- Directors
- Episode trends
- Additional insights from the dataset

The dashboard allows users to interact with the available data and explore different patterns and trends.

---

## 🛠️ Tools and Technologies Used

- **Tableau** – Dashboard development and data visualization
- **CSV** – Data source
- **Game of Thrones Dataset** – Dataset used for analysis
